# 📜 esp-car-util

A smart car utility

## Features

- Display engine stats (Coolant Temp, Engine Load, Speed) from ELM327
- Bluetooth AUX reciver

## Components

- ESP32S3 (N16R8)
- 3x Push Buttons
- Rotary Encoder Module (EC11)
- 2.8 in tft lcd (ILI9341)
